## 📂 目录结构与存放规则

为了方便大家查找与投稿，本仓库已按游戏和角色类型做好规范划分：

```text
WaifuHub/
├── 鸣潮/
│   ├── 女角色/
│   │   ├── 今汐/
│   │   ├── 长离/
│   │   ├── 椿/
│   │   └── ...
│   └── 男角色/
│       ├── 忌炎/
│       ├── 相里要/
│       └── ...
├── 异环/
│   ├── 女角色/
│   │   ├── 早雾/
│   │   ├── 薄荷/
│   │   └── ...
│   └── 男角色/
├── 战双帕弥什/
│   ├── 女角色/
│   │   ├── 露西亚/
│   │   ├── 丽芙/
│   │   └── ...
│   └── 男角色/
│       ├── 里/
│       └── ...
├── 萝莉/        <- 无需子文件夹，图片直接放在该目录下
```

- **角色专属分类**：请将图片上传至对应角色的文件夹中（如：`鸣潮/女角色/长离/`）。
- **新增角色/游戏**：如果列表中暂未收录你想投稿的角色或游戏，欢迎在对应分类下新建同名文件夹提交！
- **独立分类（萝莉 / 正太）**：无需建立角色子文件夹，直接将图片上传到 `萝莉/` 或 `正太/` 目录下即可。

## 🎨 投稿要求与图片规范

1. **画质与格式**：
   - 支持格式：`PNG`、`JPG` / `JPEG`、`WebP`。
   - 建议分辨率：尽量 1080P 及以上，画面清晰无明显噪点或严重拉伸。
2. **版权与内容红线（非常重要）**：
   - **严禁盗传商业付费画册/设定集扫描件**。
   - **严禁上传 Fanbox / Patreon / Fantia 等付费赞助专享画作**。
   - **严禁上传原作者明确注明“禁止转载”的作品**。
   - 严禁提交血腥、暴力、极端裸露或违反 GitHub TOS 的内容（避免仓库被封）。
   - 强烈建议在 PR 中注明画师 ID / Twitter / Pixiv 源链接，尊重原作者创作劳动。
3. **命名建议**：
   - 建议使用英文、拼音、数字或原文件名（例如 `changli_01.jpg`、`pixiv_123456.png`），避免过长的特殊符号。

## 🚀 零门槛投稿教程（无需安装 Git，网页直接上传）

只要拥有 GitHub 账号，只需三步即可完成投稿：

1. **找到目标目录**：
   - 点击进入对应的目录（例如进入 `鸣潮` -> `女角色` -> `今汐`，或者进入 `萝莉`）。
2. **上传文件**：
   - 点击网页右上角的 **`Add file`** 按钮，选择 **`Upload files`**。
   - 将你准备好的图片拖入虚线框中。
3. **提交 PR**：
   - 页面下方在 **`Commit changes`** 区域，选择 **`Create a new branch for this commit and start a pull request`**。
   - 点击绿色的 **`Propose changes`**（提议更改），按提示点击 **`Create pull request`** 提交即可！

管理员审核通过后，你的图片就会正式并入图库！🎉
